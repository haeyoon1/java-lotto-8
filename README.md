# 🎰 로또 미션

## ✏️ 용어 정리
| 용어 | 설명 |
|------|------|
| **input** | 사용자로부터 입력받은 값. 구입 금액, 당첨 번호, 보너스 번호 등을 포함합니다. |
| **money** | 로또 구입 금액을 의미합니다. |
| **count** | 사용자가 입력한 금액으로 구매할 수 있는 로또의 개수입니다. |
| **lotto number** | 1부터 45 사이의 정수 중 하나의 로또 번호를 의미합니다. |
| **lotto** | 6개의 `lotto number`로 구성된 하나의 로또 티켓을 의미합니다. |
| **lottos** | 여러 개의 `lotto`를 담는 객체를 의미합니다. |
| **winning lotto** | 사용자가 입력한 당첨 번호 6개를 나타냅니다. |
| **bonus lotto number** | 당첨 번호 외 추가로 주어지는 보너스 번호입니다. 2등 판별(5개 일치 + 보너스 번호 일치)에 사용됩니다. |
| **statistics** | 로또 게임의 전체 결과 통계를 관리하는 객체입니다. 등수별로 당첨 횟수를 기록합니다. |
| **rank** | 로또의 당첨 등수를 의미합니다. |
| **match count** | 각 로또가 당첨 번호와 일치하는 숫자의 개수를 의미합니다. |
| **prize** | 각 등수별 상금 금액을 의미합니다. |


## 📋 기능 목록
### 📄입력 단계 기능 목록
- [x] 로또 구입 금액을 입력 받는다.
  - [x] 구입 금액은 0보다 큰 정수입니다.
  - [x] 구입 금액이 1000원으로 나누어 떨어지지 않을 시, 예외가 발생한다.
- [x] 당첨 번호를 입력 받는다.
  - [x] 당첨 번호는 쉼표(,)를 기준으로 구분한다.
  - [x] 로또 번호는 1 이상 45 이하의 중복되지 않은 6개의 정수이다. 해당 조건을 만족하지 않을 경우, 예외가 발생한다.
- [x] 보너스 번호를 입력 받는다.
  - [x] 보너스 번호는 1 이상 45 이하의 정수이다.
  - [x] 보너스 번호는 당첨 번호 6개와 중복될 수 없으며, 중복 발생 시 예외가 발생한다.
- [x] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.

### 📄출력 단계 기능 목록
- [x] 구매한 로또 정보를 출력한다.
  - [x] 구매한 로또의 개수를 출력한다.
  - [x] 발행한 로또 번호들을 출력한다.
    - [x] 로또 번호는 오름차순으로 정렬하여 보여준다.
- [x] 로또 당첨 내역을 출력한다.
  - [x] 일치한 로또 번호의 개수 별 상금과, 개수를 출력한다.
- [x] 최종 수익률을 출력한다.
  - [x] 수익률은 소수점 둘째 자리에서 반올림한다.
